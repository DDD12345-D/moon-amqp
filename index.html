# 特性

按 AMQP 0-9-1 官方规范手写实现,每一层都以真实 broker 的字节流做交叉验证。

01线级编解码

帧、方法、content header、字段表的手写编解码器(codec / frame / table 包),大端序与位域按 §4.2.5 逐位实现。

02协议状态机

连接握手 Start/Tune/Open 状态机、Closed 终态、心跳簿记(§4.2.7),非法序列有明确报错且状态不变。

03消息全流程

拓扑声明、发布(14 个消息属性)、消费与确认:ack / nack / reject 状态机、prefetch 窗口门控、RPC 关联。

04真实 broker 验证

与 amqplib 对同一协议交换的录制帧逐字节一致的 fixture 测试(握手、拓扑、发布、消费),非仅自圆其说的往返测试。

05JS 后端驱动

driver 包完成真实会话:socket 传输经 SharedArrayBuffer + Atomics 同步,连接、开通道、收发、关闭一步到位。

06CI 端到端

GitHub Actions 5 job:check / build / test / fmt,外加对 RabbitMQ 服务容器的端到端测试,全部全绿。

# 快速开始

一条 Docker 命令起 broker,两条命令跑通 RPC 示例。

STEP 1 · 起一个本地 broker 
$ docker run -d --name moon-amqp-broker -p 5672:5672 \
  -e RABBITMQ_DEFAULT_USER=guest -e RABBITMQ_DEFAULT_PASS=guest rabbitmq:4
STEP 2 · 构建 RPC 示例(JS 后端) 
$ moon build --target js examples/rpc
STEP 3 · 运行 
$ node _build/js/debug/build/examples/rpc/rpc.js
rpc ok: fib(30) = 832040 via callback queue "amq.gen-..."

broker 地址与凭据由 RABBITMQ_HOST / RABBITMQ_USER / RABBITMQ_PASSWORD 环境变量配置(默认 127.0.0.1:5672、guest/guest)。

# 示例程序

三个可运行示例,是本库 API 的活文档,均已在真实 broker 上跑通。

work_queues

任务队列:durable 队列 + 持久消息(delivery-mode 2),5 个任务逐个确认。展示 publish / consume / ack 的最小组合。

pubsub

发布订阅:fanout 交换机 + 两个队列两条绑定,同通道双消费者,一条消息两副本逐一校验。展示 exchange / bind 与多消费者路由。

rpc

RPC 应答:exclusive 回调队列捕获 broker 生成名,correlation_id / reply_to 关联,迭代计算 fib(30)。展示请求-应答模式。

# 包结构

七个包,职责单一,各自可独立 import 与测试。

包内容
codec大端序二进制 Writer / Reader,AMQP 载荷原语
frameFrame 类型:method / content header / body / heartbeat
tableFieldTable 编解码(18 种字段值类型)
connection连接类方法、握手交换、心跳、关闭处理
channel通道类方法 + exchange / queue 拓扑管理
basic基本类方法、ContentHeader、BasicProperties、分发与确认
driver会话驱动,含 JS 后端 socket 传输
